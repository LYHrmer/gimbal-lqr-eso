# 最终仿真验收报告

2026-09-08，DM4310 MIT 与 GM6020 电流模式两套配置通过了预先确定的主工况工程门槛。**结论限于所列合成模型和基准配置，尚无硬件实测。GM 的主要收益来自积分配置，不能宣称新内核在相同参数下精度更高。**

## 独立验证组

主工况固定为 2 Hz、±5° 正弦，控制周期 1 ms、2 s 光滑启动、2–6 s 统计窗口。两电机使用相同假设负载 J=0.039 kg·m²、B=0.30 N·m·s/rad，外力矩 +0.15 N·m、平滑库仑摩擦 0.06 N·m、2 ms 力矩滞后和 1 ms 命令延迟，分别加入电机量化与力矩/速度包络。命令经过本仓库真实 C 协议编码器。

开发组为 4310–4314；下表采用配置固定后运行、未参与选择的验证组 **4315–4319**。每种电机五对原/新版全部完成、全部 RMSE 改善，新版无故障，命令达到力矩硬上限和执行器速度包络限幅的比例均为零。力矩变化率限制仍可能生效，不能把这两项零比例解释为所有限制都未触发。

| 电机 | 基准 RMSE 均值 | 新版 RMSE 均值 | 平均配对变化 | 最大误差均值：基准 → 新版 | 力矩命令 RMS 均值：基准 → 新版 |
| --- | ---: | ---: | ---: | ---: | ---: |
| DM4310 MIT，同参数 | 0.027343° | 0.025455° | −6.90% | 0.065683° → 0.059541° | 0.502926 → 0.502442 N·m |
| GM6020，最终配置对 Ki=0 基准 | 0.025383° | 0.016806° | −33.68% | 0.060083° → 0.045697° | 0.508276 → 0.507817 N·m |

百分比先对每个种子计算，再取均值，因此不必等于表中两个 RMSE 均值之比。开发组相应平均降幅为 7.50% / 34.64%，也均为 5/5 改善。完整逐种子指标、实际 C 参数和源文件哈希见 [结果表](../results/motor_profiles/README.md)、[JSON](../results/motor_profiles/metrics.json)。

[验收脚本](../tools/check_performance.py) 从逐次指标重新计算，并检查种子、轨迹/时间条件、实际 C 参数、相同积分原版对照是否完整及文件哈希。[验收结果](../results/performance_acceptance.json) 为 `passed: true`。门槛包括至少 2% 平均 RMSE 降幅、至少 4/5 改善、最大误差均值不增、力矩 RMS 增幅不超过 5%、限幅比例不增；[完整口径](performance_acceptance.md) 在保留验证组运行前确定。

## GM6020 的收益归因

最终 GM 配置增加慢积分 `Ki=2Kp=171.75392848`、积分力矩上限 0.2 N·m、回算速率 2 s⁻¹；速度误差滤波关闭。主基准保持 Ki=0，覆盖字段直接写在 profile 中。

额外对照也让固定原版 C 使用**相同积分参数**。验证组该原版 RMSE 均值为 **0.016210°**，新版为 **0.016806°**；新版相对同积分原版的平均配对 RMSE **增加 4.00%**。因此 33.68% 只能表述为“最终控制配置相对原 Ki=0 基准的改善”。新内核在有限性检查、最终限幅及故障契约方面的改进有独立回归证据，但本组没有证明 GM 同参数内核精度优势。

## 重复与独立核验

- **C 与接口**：4 个 CTest 目标通过，包含控制核心、两协议和 STM32 周期接入薄层；另在全新构建目录独立检查两静态库和配置头文件链接。AddressSanitizer / UndefinedBehaviorSanitizer 下 4 个目标均通过。
- **ARM 目标代码**：GNU Arm 10.3.1 严格 C11 编译通过，核心、两协议、周期薄层及参数探针生成 5 个 Cortex-M4F 目标文件，两种电机静态库生成成功；[编译记录](../results/arm_compile.json)。这不包含板级固件链接、MCU 执行或耗时实测。
- **数值与验收逻辑**：27 项 Python 测试，覆盖 LQR、参考导数、真实 C 仿真、原版缺陷回归、电机包络及验收器拒绝缺失/失败/改条件数据。最终 CI 会重新运行测试与完整仿真，不能仅凭本表认定未来修改也通过。
- **积分步长**：独立种子 4320，RK4 从 4 子步细化到 8 子步，共 8 次原/新试验。最大指标相对差为 6.86×10⁻⁶%，两种电机改善方向保持；[核验说明](integration_convergence.md)。
- **离散动力学**：17 个有目的的配置/延时工况、两个差分幅度，共 34 组真实 C Jacobian 与解析矩阵核对通过。分析保留不稳定工况，一致性通过不代表所有工况稳定；[局部分析](local_dynamics.md)。
- **原版直接比较及 ESO 消融**：分别保留六场景，[同参数原版对照](../results/upstream_comparison/README.md)和[新版内部消融](../results/README.md)单独报告，收益不混算。

移植以 [RoboMaster 官方 C 板例程](opensource_integration_notes.md)的任务/BSP 分层为主要参考；[STM32 C 接入示例](stm32_integration.md)与板级初始化分开。辅助模型分析的范围另见 [独立检查记录](independent_review.md)，不计作新增的运行测试。

## 已知退化边界

[26 组 DM 参数敏感性矩阵](../results/robustness/README.md)保留所有工况。真实惯量降为名义的 0.75 倍时，新版 RMSE 比原版增加 7.84%；另有较小退步与饱和场景。

GM 开发压力检查中，10 ms 命令延迟的 RMSE 从 Ki=0 原版 0.05802° 增至新版 0.10321°，约增加 77.87%；3 Hz、±10° 的受限轨迹也略有退步。慢积分、J×0.75 与 10 ms 延迟组合的局部线性谱半径超过 1。主工况验收没有覆盖这些条件，更不能把较低主工况误差推成任意延时可用。

开发阶段尝试的精确阻尼 ESO、直接观测速度反馈、2 ms 误差滤波，以及较快积分回算未通过相应开发比较，记录保留在 [development_checks](../results/development_checks/)。这些历史 JSON 是方案选择记录；当前可直接复现的发布基准由正式脚本生成，不依赖临时候选库。

电机规格、作者整车参数和未实测假设的区分见 [参数来源](parameter_sources.md)。保留种子只验证噪声变化，不构成统计置信区间、新机械模型泛化或实物性能证明；实际负载与时延需要在[台架阶段](experiment_plan.md)测量后重新设计和验证。
