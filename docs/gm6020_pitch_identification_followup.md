## 1. 本次新增了什么

相对 [早期整机测试回顾](lqr-leso-testing.md) 记录的归档，`Utils/MotorRLS.cpp` 被重写为完整的 Pitch 在线辨识模块：

| 环节 | 实现方式 | 替代了什么 |
| --- | --- | --- |
| 激励 | 7 级 LFSR 生成 PRBS(m 序列) | 原来没有专门激励信号 |
| 建模 | 积分形式辨识（ISID）：对 `τ=J·ω̇+B·ω` 做窗口积分，避免直接微分带噪角速度 | 同一思路的延续，窗口与门控重写 |
| 参数估计 | 批量最小二乘（双精度、去均值处理) | 原 `RLS<2>` 逐拍递推——用户已验证其在单精度下不收敛，予以放弃 |
| 编译期开关 | `PITCH_ID_ENABLE`，默认 **0** | — |

**此归档本身是遥控/比赛固件**：`PITCH_ID_ENABLE=0` 时 `ApplyPrbs()` 原样返回输入力矩、`UpdateRLS` 为空操作、`PrbsActive()` 恒为 `false`。辨识模块只在专门编译的调试固件中生效；归档里的 `gimbal.cpp`/`LQR.cpp` 常量变化（见下表）才是实际写回主控制链路、影响遥控固件行为的部分。

## 2. 辨识结果与写回参数

据用户记录（`docs/pitch_id_handoff.md`），三轮重复性约 0.8%，并用重力模型零点斜率做过物理交叉校核；最终采信：

| 参数 | 最终写入值 | 中间轮次出现过的值 |
| --- | --- | --- |
| J (kg·m²) | **0.0349**（±10%） | 0.0201187059 → 0.0280329827 → 0.0349 |
| B (N·m·s/rad) | **0.310** | 0.207791924 → 0.411946058 → 0.310（跨会话还出现过 0.281/0.324/0.415，用户记为弱可辨识量） |
| LQR K_θ / K_ω | **27.70586896 / 1.420355153** | 19.43577337/1.12307062 → 27.66166458/1.2254178 → 最终值 |
| LESO 带宽 | 180 rad/s（归档值，见下节） | 原 140 |
| Pitch 陀螺低通 | 独立常量 150 Hz | 原与 Yaw 共用 80 Hz |

用户的归因是：J 影响小、主要是 B 的旧估值偏高约 30% 导致闭环欠阻尼，这次改动的实质是 **K_ω 提升约 16%**，K_θ 基本未变。

## 3. 超调排查：两个假说，一个未经验证、一个被用户采信

用户报告"昨天辨识后，云台会有个超调"，并问是辨识思路问题还是控制设计问题。排查过程中出现过两个方向：

**假说 A（审查者提出，未进入归档）。** 新 J 配合 LESO 带宽 180 rad/s，扰动通道增益 `l3≈J·ω₀³` 相比旧配置（J=0.0201、ω₀=140）放大约 3.5 倍（44.8→156）。审查者在一份临时副本上把带宽改回 140 并用 `tools/pitch_lqr_eso_sim.py` 复核，名义阶跃超调由（未回退时的隐含风险）降到约 0.4%，与旧基线 0.5% 相近。**这份修改和复核只存在于临时工作目录，该目录已在环境清理中丢失，从未写回、也从未提交到此归档**——`source_manifest.json` 已核实此归档的 `k_pitch_leso_bandwidth` 仍为 180。因此假说 A 是一个有量化依据、但未经硬件验证、且已不存在于任何已审查源码状态中的候选解释。

**假说 B（用户采信）。** 审查者询问超调波形后，用户确认是"冲过目标角后再慢慢飘回（秒级）"——这与 `docs/pitch_id_handoff.md` §7.1 预先记录的、尚未修复的 AHRS 问题吻合：快速动作时加速度计读数被切向/离心加速度污染，互补滤波（`gain=0.5`）收敛期间 `INS.Pitch` 偏置约 2 秒，表现为冲过再漂回。用户据此判断"这些问题是陀螺仪解算的问题"，与辨识方法或 LQR/LESO 参数设计无关。

用户随后告知"问题已解决"。**本次审查没有获得修复后的源码、提交记录或新的实机时序日志**，因此：

- 无法确认具体修复手段——是本文档建议过的互补滤波改造（快通道编码器、慢通道 AHRS），还是 AHRS 参数调整，或其它改动。
- 无法排除假说 A（LESO 带宽）在修复中也起了作用；两者并非互斥。
- "问题已解决"是用户的原话转述，不是本仓库复算或实机日志得出的结论。

## 5. 技术方案摘要（可用于简历/展示）

- 在 STM32F407 + FreeRTOS 的 GM6020 双轴云台 Pitch 轴上，实现 PRBS（7 级 LFSR）激励 + 积分形式辨识（ISID）+ 批量最小二乘（双精度）的在线参数辨识，替代验证不收敛的单精度 RLS 递推。
- 辨识结果（J=0.0349 kg·m²、B=0.310 N·m·s/rad，三轮重复性 0.8%）反馈写入离散 LQR 增益表与 LESO 模型参数，实测于真实 GM6020 Pitch 机构（非仿真），并留有 Cortex Live Watch 实机读数影像证据。
- 排查辨识后出现的超调现象时，先建立了"LESO 扰动通道增益随带宽立方放大"的量化假说并完成仿真复核，后经用户确认波形特征（冲过再缓慢漂回）后，将根因改判为 AHRS 姿态解算在快速动作下的加速度污染，体现了"先用模型/仿真排除控制设计问题、再定位传感器融合问题"的调试路径。

**使用限制：** 本页涉及的"问题已解决"为用户口头确认，没有配套的修复后源码哈希或实机时序日志；辨识参数的最终性和视频中读数的归属轮次均存在未闭环的疑点（见第 3、4 节）。引用本页内容时，应避免写成"已验证解决超调"或"视频证明辨识精度"，建议表述为"实现了在线辨识流程并在真实机构上运行，超调现象经用户确认与控制算法无关"。
