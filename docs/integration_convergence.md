# 独立积分步长核验

固定种子 **4320**，对两个最终电机配置的 **2 Hz、±5°** 工况各运行原版和新版 C 控制器；每种组合只改变 RK4 子步数 **4 → 8**，共 8 次试验。控制周期保持 1 ms，积分步长分别为 0.25 ms 和 0.125 ms，时长 6 s，性能统计沿用主仿真的启动排除窗口。该种子未用于开发或留出集选参。

四种组合均通过运行前声明的门槛：位置 RMSE、最大位置误差、命令力矩 RMS、实际力矩 RMS 的相对差绝对值均不超过 **1%**，同时间戳轨迹的最大角度差不超过 **0.01°**。相对差按 `100 × (4 子步指标 / 8 子步指标 − 1)` 计算。

| 电机 / 控制器 | 8 子步 RMSE (°) | 8 子步最大误差 (°) | 四项指标中最大相对差绝对值 (%) | 轨迹最大角度差 (°) |
| --- | ---: | ---: | ---: | ---: |
| DM4310 / 原版 | 0.02712524 | 0.06300940 | 9.33e-7 | 2.45e-9 |
| DM4310 / 新版 | 0.02534275 | 0.05751628 | 3.36e-6 | 2.83e-9 |
| GM6020 / 原版 | 0.02598224 | 0.07313507 | 4.09e-6 | 4.53e-9 |
| GM6020 / 新版 | 0.01614824 | 0.05467232 | 6.86e-6 | 6.24e-9 |

两种积分分辨率都保留改善方向。DM4310 的新版 RMSE 分别降低 **6.571341% / 6.571343%**，GM6020 分别降低 **37.848943% / 37.848945%**。本例的正向结果没有表现出对这次积分步长细化的敏感性。

原版对照直接读取各 JSON 的 `comparison_baseline_controller_overrides`。DM4310 的覆盖为空，两版均关闭积分。GM6020 的新版采用 `Ki=171.75392848`、积分限额 `0.2 N·m`、抗饱和速率 `2 s⁻¹`；原版主对照仍为 `Ki=0`、积分限额 `0`、抗饱和速率 `20 s⁻¹`。因此 GM6020 数字比较的是最终控制方案与原配置，包含积分调参收益；不能归为纯代码实现收益。同 Ki 的额外原版对照见[两电机主报告](motor_profiles.md)。

本核验复用 `run_trial` 的被控对象积分、真实 C `WireCodec` 命令量化及同一电机包络：DM4310 经过额定速度/力矩点的分段线性模型，GM6020 使用其既定线性模型。模型、参考和随机测量序列保持一致，未增加电机通信或真实硬件数据。量化、噪声和限幅使闭环成为非光滑系统，4 对 8 子步的结果不能视为形式化四阶收敛证明，也不证明其他工况或实机稳定。

完整指标、实际传入 C 的浮点配置、原版提交信息、源码和共享库 SHA256 保存在 [integration_convergence.json](../results/integration_convergence.json)。脚本会在发现运行期间源码、配置或共享库变化时拒绝发布结果。

按 [README](../README.md) 安装依赖并构建后，在仓库根目录复跑：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
.venv/bin/python tools/check_integration_convergence.py
```

已有离线原版源码时，增加 `--upstream-source /path/to/YAW_Auto_Controller`；适配器仍校验固定提交文件哈希。可用 `--output /tmp/integration_convergence.json` 保留版本库中的结果。脚本固定种子、工况、子步数及判定门槛；全部通过返回 0，数值门槛或改善方向未通过返回 1。
