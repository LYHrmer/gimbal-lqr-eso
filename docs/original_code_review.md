# 原代码解读与改动依据

阅读基准为 [LamdaDay/YAW_Auto_Controller，665c5b4](https://github.com/LamdaDay/YAW_Auto_Controller/tree/665c5b4ab1067d6cb63122c120822f27502953e5)，不随远端 main 变化。该方案作者为戴子轩 / 南京理工大学 Combat 战队。

## 原项目每个文件负责什么

| 文件 | 作用 |
| --- | --- |
| `yaw_auto_lqr_eso_controller.h` | 参考、反馈、参数、历史状态及分项输出结构 |
| `yaw_auto_lqr_eso_controller.c` | 周期更新 ESO、前馈、LQR、积分/偏置、限幅 |
| `yaw_auto_lqr_tune.m` | 名义二状态模型及连续 LQR 调参、简化仿真 |
| `yaw_auto_lqr_eso_controller_usage.md` | 在固件中 Init/Reset/Calc 的调用说明 |

每周期控制链是：更新 ESO → 计算位置/速度误差 → 加速度、黏性、库仑前馈 → LQR 与可选位置积分 → ESO 扰动补偿 → 额外力矩偏置 → soft/hard/slew 限制。视觉包锁存、预测、包间外推和 yaw 角度跨圈由上游负责。原“soft limit”在 C 中也是数值截断，并非平滑非线性函数。

该结构的价值在于：参考速度与加速度直接参与控制，LQR 统一设计位置/速度反馈，ESO 提供模型残差估计。它并不天然保证比所有串级 PID 更好；需要相同对象与输入下的数据。

## 确认的问题与本版处理

以下行号指向固定基准 C 文件，实际复跑结果见 [回归证据](regression_evidence.md)。

| 原实现位置 | 可复现问题 | 新版处理 |
| --- | --- | --- |
| 入口 219、dt 59、Clamp 27 | 比较运算不能排除 NaN，NaN 可污染积分与最终命令 | 显式有限性检查、输出故障、锁存和清历史 |
| hard 311、slew 321 | 旧命令 5，新上限 1、100 N·m/s、1 ms 时最终仍可为 4.9 N·m | 最终硬限幅优先 |
| ESO 117–129 | 前向欧拉更新在允许的较大 dt 内可不稳定 | 预测—校正离散设计及明确周期窗口 |
| dt 59–64 | 不合法周期静默替换为 1 ms | 使用实际 dt；超窗不继续积分或观测 |
| 积分 263 | 饱和/slew 时误差积分仍持续累加 | 对最终命令反算，独立积分力矩上限 |
| bias 292 | 需求与实际受限力矩长期有差时继续积累偏置 | 新版去掉此额外调节环 |
| ESO 143 | w₀=0 时停止观测但旧扰动补偿可能仍保留 | 明确停用语义、重配清状态 |
| 原 MATLAB | 只查连续闭环极点，仿真未覆盖完整 C 控制链 | 离散极点和真实 C 核心仿真 |

原力矩偏置环不能仅凭代码称为正反馈。若测量为 `y=G(r+b), G>0`，则 `b_dot=ki(r−y)=ki[(1−G)r−Gb]`，对偏置本身是负反馈；真正需要验证的是饱和恢复、反馈比例/方向、时间对齐和环路带宽。

## 新版在数学上的变化

原版采用连续 ESO 增益再显式欧拉更新；本版对残余扰动双积分模型用预测—校正设计三重离散极点，且将名义阻尼/摩擦单独放入已知输入。二者不是只改一个参数的完全相同算法。新版完整公式、误差符号与代码字段见 [控制设计](control_design.md)。

对照实验中固定两者的模型、反馈增益、前馈、硬限幅和 slew，关闭额外积分/偏置；由未修改原版 C 与新版 C 分别计算。该对照识别此配置下的算法差异，不等价于“原作者的整套上机参数 vs 我们调好后的装置”。

## 与论坛实验的关系

论坛提供的 `/plan_yaw` 截图含慢爬升、快速换向的非正弦参考。没有原始参考 CSV、完整辨识数据及实际控制参数，无法逐点重放原实验。本仓库的 1/3/5 Hz 正弦是公开参数的合成基准。

尤其不能把论坛图片名 `3Hz20deg` 直接当作本基准的“云台 ±20°、3 Hz 正弦”。本模型下的 5 Hz 力矩需求计算，仅说明当前假设的可达性，不用于否定作者的赛场或台架自述。
