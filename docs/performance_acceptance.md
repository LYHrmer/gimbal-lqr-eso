# 仿真性能验收口径

主要工况在初次对照前固定为 2 Hz、±5° 正弦位置参考，1 ms 周期、2 s 光滑启动，2–6 s 计算真实位置误差。开发组种子为 4310–4314。根据开发结果检查方案后，另用未参与方案选择的 4315–4319 验证；两种电机都运行两组，每个种子内原版与新版使用同一被控对象、轨迹和噪声。

DM 是同参数内核对照。GM 的主对照保持原 Ki=0 基准，新版采用慢积分配置；额外原版使用相同积分参数，专门识别配置收益。验收必须保留这个额外对照，但主门槛通过不表示新版优于相同积分原版。最终验证中该相同积分原版略优于新版，见 [最终报告](validation_report.md)。

下面的工程门槛在运行保留验证组之前确定，分别对每种电机、每组五个种子检查：

- 五对必须全部完成，记录有限，新版没有控制故障。缺失或失败不能从统计中剔除。
- 五对相对 RMSE 变化的均值至少降低 2%，且至少四对改善。
- 最大绝对跟踪误差的五次均值不能增加。
- 命令力矩 RMS 的五次均值增加不能超过 5%。
- 命令达到上限的比例、执行器速度包络限制的比例，其五次均值均不能增加。

`tools/check_performance.py` 从每个种子的原始指标重新计算验收，不信任报告中的汇总数；同时核对固定种子与轨迹/时间条件、实际 C 配置、同积分原版对照、固定原版提交及当前源码/配置哈希。未通过时返回非零退出码。CI 会重新仿真后再执行这一检查。

```bash
python sim/run_motor_profiles.py
python tools/check_performance.py --output results/performance_acceptance.json
```

这个门槛用于回答“指定可达仿真工况是否有可重复、代价受控的正向变化”。它不是统计显著性检验，也没有证明所有轨迹、参数失配或真实电机都改善。其他频率、饱和边界和参数失配测试仍完整发布；保留验证种子只检验噪声变化，不代表新的机械模型或硬件泛化。
