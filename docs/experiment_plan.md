# 从电脑仿真到 DM4310 / GM6020 单轴实验

目前已有 Rudder 整车源码接入核对，但仍没有本装置的实物标定与实测记录。后续以实际装置参数替换仿真假设。以下每一步都保存配置与原始数据，便于 GitHub 结果追溯。

**按电机阅读：** [GM6020 电流模式的辨识步骤](gm6020_identification.md) · [DM4310 MIT 的辨识步骤](dm4310_identification.md)。本页保留两者共用的实验阶段与 A/B 原则。

辨识方法、参数映射和在线估计边界见 [模型辨识与整定](system_identification.md)。[RLS 实验工程](../experimental/online_rls/README.md) 可先在主机验证候选参数估计；它尚未实现本节所需的板级日志前端或自动增益切换。

上机前已修复的编译选项、Pitch 浮点边界和 RLS 异常恢复问题，以及对应复跑入口，见 [实机前软件检查](prehardware_review.md)。

## 1. 确定实际接口

记录电机完整型号/电压版本、固件版本、CAN ID、主控与控制周期、供电、负载连接方式及输出轴方向。

- DM4310 MIT：另记 Master ID 与实际 `PMAX/VMAX/TMAX`，按 [MIT 接入说明](dm4310_integration.md) 配置 `Kp=Kd=0` 的纯力矩通道。
- GM6020：按 [GM6020 接入说明](gm6020_integration.md) 确认支持并开启电流模式，记录转矩常数、电流限额和同组电机分配。由统一 CAN 调度器组织完整电流组帧。

主控决定 `valid`、反馈年龄、驱动状态与失能动作，控制器不自动发送使能。

协议映射范围不是运行上限。控制器的 `torque_limit_nm` 和编码器的独立实验限额来自同一实际限制，控制器限值不得大于协议层允许值。注意 C `float` 与协议层 `double` 的转换：例如 `0.3f` 可能略大于数学上的 0.3；必要时将控制器限额向零舍入，使编码器不会在端点把合法命令当成越界请求。

## 2. 先校核反馈，再辨识负载

确认方向和零点一致；记录主控可取得的接收间隔、发送请求和反馈时刻。只有这些记录时，不能直接断言电机采样/执行延迟。角度跨圈按实际编码器协议展开，不能把 `PMAX` 当成物理 `2π`。DM4310 的反馈映射、实验次序和最小二乘方案见 [4310 专项辨识](dm4310_identification.md)。

有负载之后，使用受限、低频的激励记录 `τcmd/θ/ω`。建立 `τ≈Jα+Bω+τc·tanh(ω/vc)`，对齐时间后再拟合。优先用积分窗口或合理滤波，避免直接对噪声速度差分得到高噪声加速度。命令力矩辨识得到的是包含执行器响应的等效模型；未经标定的反馈力矩也不能直接当作真实力矩传感器。保留独立验证轨迹检查模型误差，不把大延迟简单吸收到静态 `J/B` 后声称可忽略。

## 3. 分阶段打开控制项

先关闭 ESO 补偿与积分，用实际 `J/B/dt` 重新运行 `tools/tune_lqr.py`，在力矩受限条件下验证位置与速度反馈。参考从低频、小幅、连续导数轨迹开始；仿真的 7 N·m、±20° 和高增益不是上机默认。

基础环通过后，先开 ESO 观察而保持 `eso_gain=0`，查看估计是否噪声过大或长期撞上边界。再逐步增加补偿系数，每次只改变一类参数。若需要积分，单独验证积分增益与抗饱和，不把它与 ESO 同时调大。

## 4. 做能公平复跑的 A/B 实验

在相同安装、供电、负载、初始角度、轨迹、控制频率、限幅下比较原版与新版。交换测试顺序，避免把温升、供电变化和摩擦变化当作算法收益。每种配置建议至少重复 3 次，保存所有运行，不只选最好的一次。

记录位置 RMSE、95% 绝对误差、最大误差、命令 RMS/峰值，以及有对应诊断时的饱和比例、反馈接收年龄、故障和恢复过程。原码、名义命令力矩与测得力矩分别报告，不对缺失数据计算指标。原版与新版都用各自真实 C 实现；先进行公共参数对照，再单独报告各自调参后的对照，避免混淆算法与调参收益。

## 5. 记录格式

以实际接收和使用的数据为准：[实机数据留存规范](test_data_recording.md) 已逐项核对 Rudder 原版及移植版，可直接复制[空白模板](../examples/gm6020_rudder_template/README.md)。每个运行保留完整 `config.json`、`metadata.json`、`gimbal.csv` 和 `notes.md`；发送事件、视觉和控制器诊断按测试目的增加。

Rudder 两轴 GM6020 已有 IMU 姿态/gyro、电机角度/速度/电流原码和计算命令；温度需在收包处取单字节。真实轴端力矩、设备采样时间、CAN 完成时间和双温度不是现成字段，不列作必填。MIT 台架按 [DM4310 辨识](dm4310_identification.md) 使用独立记录格式。

实测放在已忽略的 `hardware_data/<run-id>/`，与 `results/` 的 synthetic 基准分开。模板不包含板端日志器。发布图中注明真实测量/合成仿真、重复次数、统计窗口、单位及异常运行处理方法。
