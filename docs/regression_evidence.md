# 与固定原版 C 的四项回归对照

这组检查直接执行原版 C 和本项目 C，验证四项输入与限幅边界行为。它们是确定性软件输入重放，不是实物实验，也不代替闭环跟踪误差对照。

原版固定在 [`665c5b4ab1067d6cb63122c120822f27502953e5`](https://github.com/LamdaDay/YAW_Auto_Controller/tree/665c5b4ab1067d6cb63122c120822f27502953e5)。`sim/upstream_reference.py` 核对固定源码后编译，使用原始 `YawAutoLqrEso_Calc`；适配层只映射配置、输入和诊断字段，不能提前过滤本组测试的异常输入。新版通过 `sim/c_core.py` 加载实际共享库，并由 C 编译器验证结构体布局。

## 可复跑的检查

从仓库根目录执行。新版共享库需先按仓库构建说明生成。

```sh
# 运行四项 unittest；不写任何版本结果。
python3 -s tests/test_upstream_regressions.py

# 使用本地固定版本源码，显式更新实际结果 JSON。
python3 -s tests/test_upstream_regressions.py \
  --source-dir /path/to/YAW_Auto_Controller \
  --report results/upstream_regressions.json

# 也可以由标准 unittest 发现。
python3 -s -m unittest discover -s tests -p 'test_upstream_regressions.py' -v
```

不指定 `--source-dir` 时，原版适配器使用 `build/upstream` 缓存，并按其固定版本获取流程准备源码。可用 `--library /path/to/libyaw_controller.so` 指定新版共享库。源码不匹配、库缺失或任一断言失败都会使测试失败；不会把未执行的测试标记为通过。报告只有在全部检查通过后才会写出。

共同诊断参数：`J=0.039 kg·m²`、`B=0.30 N·m·s/rad`、位置增益 20、速度增益 2，关闭积分、库仑补偿和力矩偏置；正常调用间隔为 1 ms。这些值用于隔离软件行为，不是实物整定推荐。

## 四种行为各自证明什么

1. **NaN 位置参考。** 在正常初始反馈之后传入 `NaN` 参考位置。原版没有非有限数保护；新版必须输出软件零、返回 `YAW_BAD_REFERENCE`，随后恢复合法参考也必须保持故障，直到上层显式复位。这验证了非有限命令拦截和故障锁存。
2. **在线降低力矩限额。** 先让两版命令都达到 5 N·m，然后将限额降低为 1 N·m；变化率设为 100 N·m/s，间隔 1 ms。原版先限力矩、后限变化率，旧命令附近的变化率区间可以覆盖新限额的结果。新版最后再施加绝对限额，因此缩限优先于平滑连续。这里验证的是下一次软件输出契约，不是实际电机力矩的瞬时跃变。
3. **20 ms / 50 ms 异常周期。** 观察器带宽为 80 rad/s，但关闭扰动补偿以单独观测估计器。在 1 ms 完成初始播种后，将固定反馈从 0 改为 0.01 rad，速度保持 0，目标同为 0.01 rad；按两种异常间隔重放，最多 300 次。原版诊断取真实 `z3/b0`，而非可能被限幅掩盖的最终力矩。新版有效周期区间设为 0.5–2 ms，所以必须立即返回 `YAW_BAD_TIMING`，清空控制历史并锁存故障，不执行该周期的控制/估计计算，并在恢复 1 ms 后保持锁存。**这不是同一周期下的闭环稳定性优劣比较；新版拒绝执行这些周期。**
4. **过期反馈。** 给反馈附加 10 ms 年龄，而新版超时阈值为 5 ms。原版反馈结构有有效位，但没有年龄字段；适配器如实丢弃年龄，因此原函数会继续按有效数值计算。新版必须返回 `YAW_STALE_FEEDBACK` 并锁存软件零。这是控制器内新增了新鲜度契约，不能据此断言原作者的上层系统没有做超时保护。

## 证据范围

实际输出由 [回归测试](../tests/test_upstream_regressions.py) 生成，并写入 [结果 JSON](../results/upstream_regressions.json)。JSON 保留完整配置、源码/头文件/共享库/测试/适配器 SHA-256，以及异常周期下首次大幅增长和非有限估计的步数。`NaN`、正负无穷使用字符串表示，保证结果文件是严格 JSON。

这四项通过意味着指定异常输入和在线缩限操作有了明确、可回归的处理契约。它们不能推出正常工况的 RMSE 一定更低、所有周期下都稳定，或实际电机已经停止；硬件失能、看门狗、急停和反馈时间戳仍由主控接入层落实。
