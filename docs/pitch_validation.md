# Pitch 仿真：范围与比较口径

Pitch 已有独立的真实 C 调用仿真；重力、非零平衡角、机械行程和底盘固定倾斜都进入模型。性能结果见 [完整结果与退化工况](../results/pitch/README.md)，原始指标、实际 binary32 参数和源码哈希见 [metrics.json](../results/pitch/metrics.json)。这些数据是合成仿真，不能替代实机辨识或台架验证。

| --- | ---: | ---: | ---: | ---: | ---: |
| DM4310 MIT | 0.056054° | 0.055859° | 0.015395° | −72.53% | 5/5 |
| GM6020 电流模式 | 0.027355° | 0.028304° | 0.026511° | −2.94% | 4/5 |

两个电机的留出组均通过预定主工况验收；相对新 C 关闭重力的配对改善分别为 72.44% 与 6.30%。启动段平均峰值误差也下降：DM 为 0.14100°→0.04061°，GM 为 0.15201°→0.06645°。

**GM 的证据明显弱于 DM。** GM 开发组三个种子的平均改善只有 1.41%，相对原版仅 1/3 改善，且未通过完整开发验收，因此总字段 `all_primary_acceptance_passed` 仍为 `false`。留出组也有一个种子退化 3.74%。DM 的开发组和留出组均通过。不能将 GM 的单组通过表述为跨分组稳定改善，也不能将这份 pitch 数据与先前 yaw 的不同轨迹、不同基准数字合并。

全部 32 组电机/工况比较均保留：GM 的 10 ms 延时工况 RMSE 从 0.06771° 增至 0.11946°；错误重力符号使两电机明显恶化；GM 的高重力案例超出可支撑力矩并发生机械范围越界。独立种子 5308 的 4/8 子步检查全部通过，标量指标最大相对差约 0.000025%，位置轨迹最大差约 0.0000000233°。本轮共有 150 次实际 C 闭环试验，包括主工况分组、全部边界案例和数值细化，不代表 150 次硬件实验。

比较同时保留三个实现：未修改的固定版本上游 C、新 C 关闭重力、新 C 开启重力。三者使用同一个电机配置中的 J、B、Kp、Kv、Ki、积分上限、ESO 参数和总力矩/变化率限制。GM6020 保留与上游对照相同的非零 Ki，未换成更弱的 Ki=0 基准。新 C 的两个版本保留相同机械位置检查，仅将重力系数置零，便于区分重力模型与控制内核实现的影响。

主工况在开发测试前固定：关节中心 +20°、1 Hz、±5°，采样周期 1 ms，总时长 6 s，0–2 s 为平滑启动，2–6 s 评价稳态跟踪。种子 5300–5302 用于开发检查，5303–5307 留出；未根据开发结果调整模型、增益或重力系数。验收要求相对两个对照的平均配对 RMSE 至少降低 2%，留出种子至少 4/5 改善，平均峰值误差不增加，命令 RMS 不超过对照的 1.05 倍，且无故障或机械行程越界。失败同样发布。

机械模型为：

\[
J\ddot\theta = \tau_\mathrm{motor}-B\dot\theta
-C\tanh(\dot\theta/v_c)-G(\theta)+\tau_\mathrm{external},
\qquad G(\theta)=A\cos\theta+B_g\sin\theta.
\]

这里的正角度和正力矩均表示抬起云台，零角度指水平。主工况取 A=0.45 N·m、B_g=0.10 N·m，重力幅值约 0.461 N·m，对应质量与偏心距离乘积约 0.047 kg·m。这是用于覆盖非平衡负载的示例，不能称为 RoboMaster 云台的典型测量参数。J=0.039 kg·m²、粘性阻尼 B=0.30 N·m·s/rad 沿用教学模型，另有 0.06 N·m 平滑库仑摩擦和 +0.05 N·m 外扰。

机械关节范围示例为 [-25°,45°]，参考内缩 1°。世界角用于跟踪和重力，关节角用于机械边界。固定底盘倾斜 15° 的工况将世界参考与测量同步平移，关节行程保持原定义。模拟假定底盘倾角精确已知，并将有噪声、量化的关节编码器角变换到世界系；未模拟动态 IMU 融合或姿态误差。

两个电机均调用本仓库真实 C 命令编码器，发送量化后的力矩进入 1 ms 命令延时、2 ms 假设力矩滞后和电机速度/力矩包络。反馈使用校准后均匀量化模型，未进行逐位反馈 CAN 重放。ESO 获得上一周期控制命令，不读取仿真中的瞬时实际力矩。重力项位于总力矩限幅、变化率限制和抗饱和之前；ESO 预测减去上一周期已知重力，避免再次将该部分当作未知扰动补偿。

每个电机完整保留 16 个预先声明工况：主工况、重力 ±25%、重心相位偏移 15°、惯量 ±25%、噪声三倍、10 ms 命令延时、1.5 Hz 轨迹、负俯仰角、接近上限、固定底盘倾斜、错误重力符号、已配平却仍使用错误模型、高重力负载、越过参考内缩范围。全部计划见 [experiment_plan.json](../results/pitch/experiment_plan.json)。错误标定、长延迟和力矩不足的退化不能从结果中删除。

物理位置从不被夹在机械限位上。首次越界即记录失败并停止该段无接触模型的积分；失败段中的局部 RMSE 仅供诊断，不进入成功比较。软件故障锁定后命令归零，重力负载仍可能跌落，因此“拒绝越界参考”不等于制动、机械限位或安全保持。上游对照只覆盖公开控制器 C，不代表原作者整车上层没有限位和保护逻辑。

独立数值检查使用额外种子 5308，对三个 C 实现分别将 RK4 每周期子步从 4 加倍至 8。预定阈值为四项标量指标的相对差不超过 1%、整段位置轨迹最大差不超过 0.01°。量化及限幅系统不据此宣称形式上的四阶收敛率；这项检查只用于排除当前时间步长造成的明显数值假象。

复现命令（先按仓库说明构建共享 C 库和准备 Python 依赖）：

```bash
python3 sim/run_pitch_profiles.py --phase full --output build/pitch-reproduction
python3 -m unittest discover -s tests -p test_pitch_simulation.py -v
```

脚本默认保留性能验收失败的结果；`--require-primary-improvement` 可额外要求两个电机均通过主工况性能验收，否则返回非零。有限步长细化检查失败、运行中源码变化等实验有效性问题始终返回非零。Pitch 相关的 7 项 Python 测试覆盖重力势能梯度、世界/关节角转换、真实 C 调用的重复性、不可支撑负载越界，以及验收拒绝缺失种子、不匹配增益、非有限指标、故障与伪造改善百分比。

本轮尚未建模电机热过程、回生电压、摩擦迟滞、背隙、柔性连接、硬限位碰撞、动态底盘运动与 yaw–pitch 耦合。GM6020 示例 1.2 N·m 总力矩上限也不是全部转速、姿态下可无限期保持的承诺。移植与标定步骤见 [pitch 接入说明](pitch_integration.md)。
