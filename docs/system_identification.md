# 模型辨识与参数整定

[项目首页](../README.md) · [文档导航](README.md) · [RLS 实验工程](../experimental/online_rls/README.md)

本项目以实际机构的模型指导整定。电机型号相同，不代表惯量、阻尼、延迟或重力负载相同。建议流程为：**校准与采集 → 辨识候选模型 → 独立验证 → 模型族上的整定 → 冻结配置 → STM32 实验**。

## 当前实现到哪一步

| 环节 | 已有能力 | 尚未实现 |
| --- | --- | --- |
| 控制与记录接口 | C 控制器暴露力矩分项、状态和限幅标记；STM32 周期示例有来源时间 | 具体板级 CAN/IMU 日志采集、全链路时序对齐 |
| 参数估计 | 独立 C RLS、主机激励判断、合成回归流测试 | 实测 CSV 一键拟合、闭环 IV/PEM、三轴耦合辨识 |
| 离线整定 | `tools/tune_lqr.py` 由 `J/B/dt/Q/R` 计算离散 LQR | 自动选择完整 LQR/ESO/Ki 配置 |
| 参数导出 | 两电机 `simulation_only` JSON → C 参数头 | 带实测标定与验收状态的配置导出 |
| 部署与验证 | 实际 C 仿真、协议适配、ARM 编译 | 本项目电机实测、在线无突变增益切换 |

RLS 位于 `experimental/`，默认不构建、不链接到电机控制库。在线拟合候选参数与在线修改控制器是两个独立环节。

## 1. 先核准力矩、时间和坐标

日志同时保留限幅前输出、最终受限命令、线上编码、可获得的电流/转矩原码，以及各自来源时间。CAN 已发送的命令不自动等于真实轴端力矩。

- DM4310 保持 MIT 纯力矩 `Kp=Kd=0`，核对实物 `PMAX/VMAX/TMAX`。反馈转矩可能是内部估算值，需要声明标定依据。
- GM6020 先确认固件与电流模式；反馈电流原码不能未经确认直接套用命令侧比例，见 [GM6020 接入](gm6020_integration.md)。
- 力矩标度未知时，可先辨识命令到运动的有效模型，但不能同时宣称绝对惯量和力矩增益都已独立确定。
- 延迟与执行器滞后应单独建模或给出不确定范围。互相关峰也包含对象动态影响，不能只凭它断言传感延迟。
- 控制核心的 `applied_torque_nm` 需要前一完整控制区间的平均执行力矩；当前瞬时电流不自动满足该契约，默认 STM32 示例未启用此反馈。

采集字段和实验记录见 [单轴实验步骤](experiment_plan.md)。保留缺失、限幅、模式切换和异常标记，禁止用零伪装没有测到的力矩。

## 2. 先拟合少量物理参数

其他轴固定、坐标一致时，可从下面的单轴模型开始：

```math
\tau_a=J\dot\omega+b\omega+f_c\tanh(\omega/v_c)
       +g_c\cos\theta_g+g_s\sin\theta_g+\tau_0.
```

第一版宜先标定重力与摩擦，再在线拟合 `J/b`。已知项从标签中扣除，用同一积分窗口构造：

```math
\int(\tau_a-\tau_{known})dt=J\Delta\omega+b\Delta\theta.
```

积分减轻直接差分的噪声问题，但不消除闭环偏差、回归量测量误差或时间错位。窗口过长覆盖完整周期时，`Delta omega` 可能趋近零，反而失去惯量信息；邻接窗口也可能共享带噪声端点。

| 需要分开的量 | 有帮助的实验 | 主要限制 |
| --- | --- | --- |
| Pitch 重力、偏置和摩擦 | 多姿态停留、正反方向接近、缓慢双向扫角 | 窄角度下 cos 项与常量近共线，静摩擦也会影响保持力矩 |
| 阻尼和运动摩擦 | 双向、多速度运行 | 一个方向匀速不能识别完整参数组合 |
| 惯量和动态响应 | 稳定闭环下独立、受限的多频参考或力矩激励 | 激励频段和幅值按机构、电流环、噪声与约束选择 |
| 模型适用范围 | 独立幅值、姿态、载荷与重复实验 | 一个工作点的良好拟合不能证明全工作域有效 |

`v_c` 先固定或离线搜索；同时将其作为未知量会改变线性回归结构。Pitch `g_c/g_s` 可以为负，不能一律套用非负约束。垂直 Yaw、省略重力的假设也需在基座倾斜时重新检查。

## 3. 在线 RLS 的职责和限制

RLS 每次用新回归量与观测更新参数和逆加权信息矩阵 P。`lambda=1` 用于固定参数；小于 1 会降低旧数据权重，同时增加噪声敏感性。遗忘时间必须按有效更新频率解释，不能直接照搬另一个项目的 lambda。

[当前 C 原型](../experimental/online_rls/README.md) 在样本无效、激励不足、异常创新、参数越界或矩阵检查失败时，冻结参数和 P。近期信息统计由主机示例继续推进，避免起始无激励导致永久停止；板级前端仍需实现。

普通 RLS 不自动解决闭环输入与噪声相关的问题。可以将稳定闭环下的独立参考/注入作为工具变量候选，或采用带合理噪声模型的预测误差方法；工具变量本身也必须满足相关性与独立性条件。小残差或小 P 都不是参数正确的充分证据。

ESO 估计剩余扰动，RLS 估计有足够数据支持的模型参数；不能把 ESO 自己的输出当作独立测得的真实负载。停更期间对象仍可能变化，冻结也不意味着旧模型依然准确。

## 4. 把参数送入已有控制器

| 辨识结果 | 当前接口 |
| --- | --- |
| 惯量 | `YawConfig.inertia_kg_m2` |
| 黏性阻尼 | `damping_nm_s_rad` |
| 摩擦幅值与过零平滑 | `coulomb_nm / coulomb_velocity_rad_s` |
| Pitch 重力 | `GimbalConfig.gravity_cos_nm / gravity_sin_nm` |
| 其他已知负载 | `yaw_controller_step_with_load()` 的当前/上一周期负载 |
| 执行器延迟、滞后 | 仿真模型；当前 C 核心没有对应显式补偿器 |

`tools/tune_lqr.py` 对名义模型进行精确 ZOH 和 DARE 求解，也支持 `b=0` 的双积分器。`Q/R` 不由 `J/b` 唯一确定，可按允许误差和力矩尺度归一化后形成候选。

随后在实际 C 仿真中联合考察模型不确定性、延迟、协议量化、噪声、饱和与恢复。ESO 带宽不是越大越好；二状态 LQR 没有联合设计积分，Ki 与抗饱和仍需单独验证。

当前参数在 init 前设置，在线 setter 仅支持力矩限额。第一版建议候选参数经离线验证后，在明确停止控制并准备恢复时换入配置；初始化会清除历史并 warmup 零输出。运行中无突变切换需要另外设计。

## 5. 证明模型和整定确实有用

按完整实验划分辨识、整定验证和最终测试，不能随机打散相邻时序后称独立数据。模型验证同时看自由仿真、一步预测、目标频带幅相和残差，并输出合理的不确定范围。

控制验证比较同一对象、参考、力矩约束和初始条件下的当前配置与候选配置。增加模型替换、增益变化的消融对照；不仅看平均 RMSE，也看最坏误差、力矩波动、饱和、振荡、故障和恢复。参数恢复实验与控制性能实验分别报告。

模型、基线、预处理、门槛和数据划分冻结后才使用最终测试；看过结果继续调参，需要新的一轮独立数据。哈希有助追溯，但不等于盲测保证。[RLS 发布结果](../results/online_rls/README.md) 目前是合成回归数值验证，不能替代本步骤。

## 6. 大 Yaw—小 Yaw—Pitch

按“轴角色、机构/载荷、电机/固件、工作姿态”保存参数，不能只按电机型号分两套。大 Yaw 承载下游机构，小 Yaw 的惯性响应与末端绝对运动有关，而轴承摩擦与相对关节运动有关。

先得到其他轴固定的条件模型，再用父轴运动和独立交叉激励验证耦合。两个 Yaw 始终按固定比例运动会损失可辨识信息。编码器多圈关节角、世界姿态和重力倾角各有用途，详见 [多轴接入](multiaxis_integration.md)。
