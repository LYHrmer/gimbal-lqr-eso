# GM6020：从电流组帧日志到每轴模型

[辨识总览](system_identification.md) · [电流协议接入](gm6020_integration.md) · [数据留存规范](test_data_recording.md) · [空日志模板](../examples/gm6020_rudder_template/README.md) · [DM4310 专项](dm4310_identification.md)

**GM6020 先确认电流模式，分别核准命令和反馈的标度，再辨识当前安装负载。** 第一版在已稳定、受限的外环中采集，先离线验证候选模型；本页不是实测结果，也不提供自动采集或 CSV 一键拟合程序。

## 1. 确认实际电流模式和总线分工

官方 v1.4 手册要求电机固件 **≥1.0.11.2**、RoboMaster Assistant **≥2.7**，并在参数设置中打开电流环。保存实物固件与模式确认记录；代码中的 `current_mode_confirmed=true` 不会配置驱动。[官方手册，印刷页 6](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf#page=7)

电流命令组 `0x1FE` 对应电机 ID 1–4；`0x2FE` 对应 ID 5–7，第四槽保留为零。它们都是 8 字节标准数据帧，四槽为大端有符号 16 位。命令 `±16384` 对应 `±3 A`；电压组 `0x1FF/0x2FF` 不能混用，本库不提供电压控制后备路径。[官方电流协议，印刷页 6–7](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf#page=8)

已核对的 Rudder 原版与 LQR 移植版**本来都发送电流组 `0x1FE`**，两轴映射如下；这是源码事实，实际接线及电机设置仍需确认。

| 轴 | 原工程对象 | 反馈 | 命令组与槽位 |
| --- | --- | --- | --- |
| Yaw | `motor_[0]` | CAN1 / `0x206`，电机 ID 2 | CAN1 / `0x1FE` 第 2 槽 |
| Pitch | `motor_[1]` | CAN2 / `0x205`，电机 ID 1 | CAN2 / `0x1FE` 第 1 槽 |

每条总线的同一组帧只能有一个发送者，集中汇总该组所有电机的本轮命令。辨识某一轴时也不能清空组帧后只填自己，覆盖其他轴的有效输出；缺失、过期和停止时的整组行为要明确。本库 `gm6020_torque_to_word()` 只换算单轴，`gm6020_pack_current_group()` 才组装四槽快照；两者均不执行 CAN 发送。

## 2. 分清能测到的量和名义换算

| 量 | 当前可用来源 | 辨识中的含义 |
| --- | --- | --- |
| 控制请求、限幅后命令 | 外环、限幅器、实际组帧槽位 | 保存各阶段；机械模型不能只用限幅前请求 |
| `current_wire_a / torque_wire_nm` | 公共编码器根据量化后命令反算 | 名义电流/力矩，不是反馈或已执行证明；旧移植需离线按其实际映射换算 |
| 电机角度与速度 | 反馈编码器 `0..8191`、有符号 RPM；原工程 `GetAngle()/GetSpd()` | 公共解析器给单圈 rad、rad/s；原工程角度已展开且单位 deg，零位仍需校准 |
| `current_raw` | 公共解析器；原工程 `GetCurrent()` | 有符号原码，当前不自动换成 A 或 N·m |
| 单路温度 | 反馈 byte 6 | 公共解析器为 `temperature_c`；原工程字段私有，可从完整原帧记录 |
| IMU 姿态与速度 | 原工程 INS；移植版控制输入快照 | INS 姿态为 deg，body gyro 为 rad/s；不能直接把 gyro 分量当世界 Euler 角导数 |

v1.4 反馈表没有明确电流回读的 **A/count**，不能照搬命令的 `3/16384`。该反馈也没有真实轴端扭矩、母线电压、双路温度、电机采样时间戳或统一故障状态字；本方案不要求填写这些不存在的测量。[反馈表，印刷页 7](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf#page=8)

名义命令换算为 `I_cmd=raw*3/16384`、`tau_cmd=Kt*I_cmd`。手册给出 `Kt=0.741 N·m/A`，但 `3*Kt=2.223 N·m` 只是协议端点换算，不是连续工作能力或实测峰值。实验限额按实物负载、速度和热条件独立设定，不能用满量程作默认激励。[官方参数，印刷页 11](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf#page=12)

## 3. 标度未校准时先报告有效模型

先选择一种有明确单位的输入标签 `u`：实际提交的命令原码、名义命令电流，或经独立校准的反馈电流。不同标签分开拟合，不能逐点混用。若真实力矩近似 `a_u*u`，则

```math
a_u u=J\ddot q+B\dot q+F_c\tanh(\dot q/v_c)+\tau_g+\tau_0.
```

标度未知时可估计 `J/a_u、B/a_u、F_c/a_u` 等组合，无法从同一数据独立确定 `a_u` 与绝对惯量。输入为命令时，还会包含电流环、通信和限流的动态影响。把结果称为该输入标度下的有效模型，不能直接填入物理单位字段并声称得到实测 `J/B`。

需要物理参数时，先确认反馈电流比例与零偏、`Kt` 适用性及传动关系，可结合已知力臂/负载、多点、双方向静态校核；保存标定原始数据与温度、摩擦、损耗不确定性。电源电流不等于驱动转矩电流，不能直接拿电源显示值替代反馈标定。标度核准后，`Kt*I_feedback` 仍是电流模型的力矩估计。

角度与力矩统一到同一坐标。例如关节角 `q=r*theta_m+q0`，含方向的理想传动应满足 `omega_q=r*omega_m`、`tau_q=tau_m/r`；效率与摩擦另处理。先固定父轴，核准电机角与 IMU 姿态的关系；父轴运动时两者不再描述相同运动。

原 Rudder 与移植版的 Pitch 在控制力矩转 CAN 原码时还施加了负号。将 raw 换成名义电机力矩后，仍须按实际配置的方向变换到控制坐标，再拟合或与 `torque_nm` 比较；不能直接拿 Pitch 的 CAN 符号作差。

## 4. 实际取样与日志

复制 [GM6020 两轴空模板](../examples/gm6020_rudder_template/README.md)，附固件哈希、完整参数、安装负载、时钟、采样策略与试验说明。模板只有表头和元信息，**复制后仍需实现有界缓冲记录和导出**，当前没有 CSV 拟合器。

- **控制流：** 原版实际参考在被调用的 PID 处取样，不能以 `set_yaw_/set_pitch_` 代替；移植版取 `RudderLqrCompute()` 当次 `input/result`。保留有效性、age、模式、warmup/停止/故障与实际限额；未计算诊断的零不能当零跟踪误差。
- **反馈流：** 完整收包回调保存原始 8 字节、CAN 总线/ID、本地主控接收时刻及解析结果。主日志取最近值不等于每周期都有新反馈；额外记录丢帧/日志溢出及来源关联。
- **发送流：** 在 CanTask 记录当次实际四槽实参，包括零命令。原 `DjiMotorSend()` 丢弃 HAL 返回值，状态留空；移植版可记录。`HAL_OK` 仅表示请求受理，不能填成发送完成或力矩执行。

失败或状态未知的发送区间保留，但不能把新命令当作已施加输入，也不能将未知实际输入补成零；机械辨识窗口需据此分段。即使请求受理，也需评估驱动延迟与内部限流。`commands.csv` 与反馈按实际来源对齐，不能简单按行号配对。

原工程可记录 `HAL_GetTick()` 的 uint32 毫秒值，移植版另有 DWT 周期差算出的 `input.dt_s`。毫秒乘 1000 不会产生微秒精度；旧 `DWT_GetTimeline_us()` 也不能未经检查当可靠长时钟。记录回绕、重启、真实周期与延迟范围，不能把 INS、控制、CAN 统一假设成严格 1 kHz。

现有 USB CDC 用于视觉、USART3 用于遥控接收、USART6 用于裁判系统，没有现成 VOFA 日志器。先确认导出通道和带宽，再异步发送；不得因记录阻塞控制任务。取样位置、旧离线状态局限及模板列的完整定义见[数据留存规范](test_data_recording.md)。

## 5. Yaw 与 Pitch 分别怎样做

先用已有稳定的保守外环完成方向、行程、失联与停止检查，再冻结本次幅值、频段和限额；不要用未辨识的示例 LQR 参数直接施加裸电流激励。温度、饱和、振动和反馈异常决定是否停止扩展激励，失败运行同样保存。

| 阶段 | Yaw | Pitch |
| --- | --- | --- |
| 静止与慢速往返 | 父轴固定，检查展开角、噪声、线束阻力、过零滞回 | 多姿态停留，从正反方向接近同一角度，观察重力与静摩擦 |
| 双向多速度 | 多个正反向近匀速段区分 `B/Fc/偏置` | 在多个已校准姿态重复，避免把重力变化算成阻尼 |
| 小幅动态激励 | 稳定外环内加入独立多频参考或受限附加电流，保留加减速信息 | 在已确认行程内做同类激励，保持足够重力支撑余量 |
| 独立验证 | 改变参考相位/轨迹并重复，检查不同负载 | 覆盖拟使用的姿态与载荷，检查重力补偿和回程差 |

最高激励频率根据实际有效反馈速率、执行器和机构带宽选定；纯匀速不能辨识惯量，满周期平均也可能消掉惯量信息。近似竖直且基座固定的 Yaw 可省略重力项；倾斜或父轴运动时须重新验证该假设。

Pitch 区分机械关节角 `q` 与重力倾角 `theta_g`。通用接口以水平为重力零位、抬头为正，可用 `tau_g=gc*cos(theta_g)+gs*sin(theta_g)`；只有固定基座、轴向与零位已标定时才能用 `theta_g=q+theta0`。原 Rudder 的电机角尚不等于已标定机械零位，旧三次保持曲线也只是移植假设。[Pitch 接口](pitch_integration.md)

窄角度内重力余弦项与常量偏置可能难以区分；双向接近可以观察静摩擦，不保证消除它。`gc/gs` 允许有符号，重力零位与系数相位不能无约束重复拟合。优先固定已独立校准的项，再估计少量未知参数。

## 6. 积分最小二乘得到候选参数

将断流、重启、模式切换、展开失败和输入未知的区间分开；保留原始值与筛选理由。确认力矩标度后，对同一有效窗口构造：

```math
\int\tau_{label}\,dt=J\Delta\omega+B\Delta q+F_c\int\tanh(\omega/v_c)\,dt
 +g_c\int\cos(\theta_g)\,dt+g_s\int\sin(\theta_g)\,dt+\tau_0\Delta t.
```

标度未确认则以 `u` 为标签，报告第 3 节的归一化系数。`q` 用 rad、`omega` 用 rad/s；先固定 `vc`，Yaw 删除不需要的重力项。已知项可先扣除，只拟合 `J/B`。列归一化后用 QR/SVD 检查秩与条件性，不直接求正规矩阵逆。

积分减少直接差分角加速度的噪声，但不消除时间错位、测量误差或闭环偏差。若滤波，应对回归方程各项一致处理并记录延迟；不能仅平滑速度。稳定外环内的独立参考/注入可作为 IV 候选，但仍需检验相关性与独立性；本仓库尚无实测 IV/PEM 实现。方法与限制见[辨识总览](system_identification.md)。

## 7. 接入已有工具并证明有用

| 环节 | 仓库已有 | 本次实机仍需补齐 |
| --- | --- | --- |
| 协议换算 | [gm6020.h](../include/gm6020.h)、完整组帧和反馈解析 | 实物模式确认、标度、板级调度与上述日志 |
| 递推候选 | [独立 C RLS](../experimental/online_rls/README.md) 与合成实验 | 真实积分窗口、激励判断、有效样本与采用流程 |
| 名义增益 | [tune_lqr.py](../tools/tune_lqr.py)，从 `J/B/dt/Q/R` 求 LQR | ESO/Ki 联合验证、模型不确定范围及硬件 A/B |

RLS 第一版旁路估计已充分激励的 `J/B`，重力和摩擦先固定；无效、无激励或异常更新时冻结候选，记录原因。遗忘因子按实际有效更新间隔解释，不直接套用合成脚本的窗口或阈值。小残差、小 P 或更接近某个参数值，不等于控制性能改善；当前没有运行中热更新增益的实现。

按完整运行划分辨识、整定验证和最终测试。先核对独立轨迹预测、自由仿真、残差及频带响应，再用实际 C 控制器在同一对象、参考、限额、使能条件下比较位置误差、命令波动、饱和、超时和恢复，保留重复次数、失败及排除时长。对照顺序交替，配置与门槛预先冻结。

Rudder 原版自瞄 Yaw 强制清零，移植版默认也可保持禁止；记录 `RUDDER_USE_LQR / RUDDER_AUTO_YAW_ENABLE` 与实际分支，不能把启用差异算作算法改善。候选通过后在明确停止、重新初始化时换入配置。三轴先辨识其他轴固定时的条件模型，父轴运动后的耦合还需独立验证。
