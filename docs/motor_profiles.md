# DM4310 MIT 与 GM6020 电流模式两套配置

两套配置共用便携 C 控制器，但使用各自的命令编码、传感器量化与力矩约束。它们都是 `simulation_only` 的离线参考；负载 J/B 是为受控对比而共用的假设值，不能因为电机型号相同就视为已辨识的硬件参数。

| 项目 | DM4310 24 V | GM6020 当前电流模式 |
| --- | --- | --- |
| 配置文件 | [dm4310_24v.json](../profiles/dm4310_24v.json) | [gm6020_current.json](../profiles/gm6020_current.json) |
| C 命令转换 | `dm_mit_encode_torque()`，MIT 的 `kp=kd=0` | `gm6020_torque_to_word()`，有符号电流命令 |
| 仿真应用力矩上限 | 3 N.m | 1.2 N.m |
| 名义 J / B | 0.039 kg·m² / 0.30 N.m·s/rad | 相同，便于比较 |
| LQR 位置 / 速度增益 | 85.87696424 / 3.07876864 | 相同 |
| ESO 带宽 / 补偿系数 | 80 rad/s / 0.8 | 相同 |
| 积分 | 关闭 | `Ki=171.75392848`，力矩上限 0.2 N.m，回算速率 2 s⁻¹ |
| 速度误差滤波 | 关闭 | 关闭 |
| 命令变化率上限 | 100 N.m/s | 100 N.m/s |
| 控制周期 / 假设执行器滞后 / 命令延迟 | 1 ms / 2 ms / 1 个周期 | 相同，均不是硬件实测时延 |

GM6020 使用官方 `Kt=0.741 N.m/A` 与 `±16384 ↔ ±3 A` 的电流命令映射。驱动必须具备并确认当前电流模式，不能把旧的电压命令字段当成电流使用。编码器按应用力矩和电流限额约束，再把量化后的 wire current / wire torque 返回给仿真；没有 CAN 发送操作。模式/固件要求见 [GM6020 接入说明](gm6020_integration.md)。DM 的 `PMAX/VMAX/TMAX` 在此是明确的仿真映射，硬件需要读回；见 [DM4310 接入说明](dm4310_integration.md)。

DM 命令物理零点并非恰好对应一个 MIT 力矩量化码，默认映射下零请求约为 +0.002442 N.m；这不等于真实电机的测得零力矩。GM 的有符号电流协议可以表达精确的零命令。两者的 command 都经过真实 C 转换，而反馈是校零后的均匀间隔量化假设，不是逐 bit 的 CAN 反馈回放。

DM 驱动包络经过假设的零速 7 N.m 截距、规格的 120 rpm / 3 N.m 与空载 200 rpm / 0 点；GM 使用规格转速/力矩梯度形成直线。两者都只是静态近似，制动方向尚未模拟回馈母线约束，也没有热模型。GM 手册持续堵转力矩另为 0.86 N.m，因此不能把 1.2 N.m 配置解释为任意低速无限持续允许值。规格出处和假设分类见 [参数来源](parameter_sources.md)。

GM 的积分是一个明确的配置变化。`Ki/Kposition=2 s⁻¹` 使误差修正慢于主 LQR 动态；积分主要补偿 ESO 只施加 0.8 倍扰动估计后留下的恒外扰残差。原先 20 s⁻¹ 回算速率在粗速度量化和命令变化率限制下会把削顶残差过快回灌积分，因此开发检查改用与慢积分相称的 2 s⁻¹。没有通过搜索种子或扫描大量增益选取这一设置；失败的开发候选也保留了结果。

基准规则写在 JSON 的 `comparison_baseline_controller_overrides` 中：DM 为空；GM 原版基准恢复 `Ki=0、积分上限=0、回算速率=20`。GM 报告另跑**完全相同积分参数的原版 C**，以分清“调参带来的收益”和“内核实现差异”。两种原版对照都调用固定提交的真实 C 文件，没有用 Python 重写控制器。

```bash
python sim/run_motor_profiles.py
```

脚本先评估四个预定频幅组合，再给每种电机的 2 Hz / ±5° 主工况运行开发种子 4310–4314 与独立验证种子 4315–4319。CSV 保存主工况 seed4310 的完整轨迹；JSON 与结果表保存每个种子的 RMSE、最大误差、命令 RMS、实际力矩、限幅和故障，并计算相同积分原版的差值。完整数据见 [双电机结果](../results/motor_profiles/README.md)，敏感性与已知退步边界见 [robustness.md](robustness.md)。

冻结配置后的五个独立验证种子结果如下；百分比是各 seed 配对相对变化的平均：

| 电机 | Ki0 原版平均 RMSE | 新版配置平均 RMSE | 平均降低 | 五个种子中最小降低 |
| --- | --- | --- | --- | --- |
| DM4310 | 0.027343° | 0.025455° | 6.90% | 5.57% |
| GM6020 | 0.025383° | 0.016806° | 33.68% | 26.92% |

两者五个验证种子都改善了相对基准的 RMSE，最大误差均值下降，命令 RMS 略降，主工况没有力矩/包络饱和或新版故障。**GM 的配置收益不能等同于内核优势**：与相同积分参数的原版 C 比较，新版在验证组的平均配对 RMSE 反而高 4.00%，开发组则低 0.65%；两组第三列均已公开。独立 seed4320 的 4/8 子步积分收敛检查也保留在 [收敛记录](integration_convergence.md)。

这些比较能说明所列合成工况中的软件与配置变化。GM 10 ms 延迟和高幅饱和工况已有退步，因此上机前仍需要确认真实时延、实际负载及可用力矩；本项目没有声称复现论坛原始轨迹或已经证明硬件性能提升。
